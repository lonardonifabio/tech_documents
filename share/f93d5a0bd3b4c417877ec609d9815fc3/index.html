  • Autonomy (or decision-making): Degree to which an agent can decide when and how to act towards a goal, such as by defining the steps to be taken in a workflow. This can be determined by its instructions and level of human involvement.
  • Action-space: An agent’s action-space mainly depends on the tools it has access to, which can affect Systems it can access : Sandboxed tools (e.g. for code execution, data analysis) that cannot affect any other system, Internal systems: Tools internal to the organisation, such as being able to search and update the organisation’s databases, External systems: Tools that enable the agent to access external services, such as retrieving and updating data through third -party pre -defined APIs.
  • Computer use agent: An emerging modality of agentic AI is a computer use agent, whose primary tool is access to a computer and browser.
  • Agentic systems require careful judgment and analysis due to task complexity and unpredictability.
  • Agent access to external systems introduces vulnerabilities like prompt injections and cyberattacks, necessitating restricted access to trusted internal knowledge bases.
  • Threat modelling and taint tracing are crucial techniques for systematically identifying and mitigating risks in complex agentic systems, particularly concerning untrusted data flow.
  • Organizations can adapt governance with new agentic developments.
